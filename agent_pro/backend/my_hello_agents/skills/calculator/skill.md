# 计算器 Skill

当用户需要数值计算(加减乘除、百分比、括号表达式、幂运算等)时,使用本 skill 的 calculate 工具完成精确计算,不要心算或估算。

## 执行链路
1. 从用户问题中提取完整数学表达式
2. 调用 calculate(expression) 得到精确结果
3. 用简洁中文把结果和简要推导呈现给用户
4. 若工具返回错误,请根据错误信息修正表达式后重试一次,仍失败则如实告知用户
